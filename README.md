# 🧬 MediScan AI — Disease Prediction System

A machine learning web app that predicts diseases based on selected symptoms, built with Flask and a 3-model ensemble classifier.

## Features

- 132 symptoms across 10 categories (Skin, Digestive, Respiratory, etc.)
- Predicts from 41 diseases with confidence scores
- Top 3 predictions with probability bars
- Disease info panel — description, causes, when to see a doctor
- Symptom importance — which symptoms drove the prediction
- Minimum 3 symptoms required with toast validation
- Fully responsive UI with animations

## Tech Stack

- **Backend:** Python, Flask
- **ML:** scikit-learn (Random Forest + Gradient Boosting + Extra Trees ensemble)
- **Frontend:** HTML, CSS, Vanilla JS
- **Data:** Excel dataset (4961 samples, 41 diseases, perfectly balanced)

## Setup

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/mediscan-ai.git
cd mediscan-ai

# 2. Create virtual environment
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # Mac/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Train the model (only needed once)
python model.py

# 5. Run the app
python app.py
```

Then open `http://127.0.0.1:5000` in your browser.

Or just double-click `start_app.bat` on Windows.
